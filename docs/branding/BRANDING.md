# Fakturenn / Tailh shared branding

## Wordmark
Both logos now use exactly the same typography:

- Font: Inter
- Weight: Bold (700)
- Font size: 158px
- Baseline: y=625px
- Wordmark start: x=650px
- Color: #001f40

`Tailh` is intentionally narrower because it is a shorter word. It is not enlarged to fill the available width.

## Artwork
The original lighthouse/document artwork from the supplied images is preserved.
Only the AI-generated wordmark area was removed and replaced with deterministic Inter text.

## SVG note
The SVG masters are hybrid assets: the icon artwork remains raster, while the wordmark is real SVG text.
For editing, install Inter. For a font-independent final SVG, convert the wordmark to paths in Inkscape.
